Connect your YouTube key

This dashboard reads public view counts straight from YouTube's Data API. It needs a free API key. Your key is stored only in this browser — it never goes to the page's host or anywhere else.

  1. Open Google Cloud → Credentials and create a project (any name).
  2. In API Library, enable YouTube Data API v3.
  3. Back in Credentials, click Create credentials → API key and copy it.
  4. Recommended: edit the key → Application restrictions: Websites → add this page's address, so only this site can use it.
